# 需要从上游规则中剔除的片段（子串匹配，命中即丢弃整条规则）
#
# 上游 AdBlockLite 里这一条的字符类写错了：`[^(apple|10010)]` 不是“排除 10010 相关域名”，
# 而是“匹配任何不含这些字符的串”，于是像 https://t.snssdk.com/ad/... 这类正常广告路径之外的
# 请求也可能被替换成 1px 图，属于典型的过宽规则。中国联通的广告端点已在别处精确列出，
# 这里直接剔除，并在 10-general.conf 增补里给出精确规则。
^https?:\/\/[^(apple|10010)]+\.(com|cn)\/(a|A)d(s|v)?(\/|\.js)

# 上游把 kfc 的域名写成了 `kfc\.com.\cn`（少了转义、多了通配），PCRE 下会被解释成控制字符 \cn，
# 既拦不到也说不清，直接剔除并在 10-general.conf 增补里给出正确写法。
^https?:\/\/res\.kfc\.com.\cn\/advertisement\/

# lal_douyin 引用的抖音脚本已被上游删除（2026-09 实测 404：fmz200/wool_scripts 里已无 douyin.js），
# 留着只会让 Plus 版每次为一条死链白跑一次脚本加载，直接剔除。
fmz200/wool_scripts/main/Scripts/douyin/douyin.js

# 抖音的 302 跳转（api*.amemv.com/aweme/v1 -> aweme.snssdk.com/aweme/v1）本来是配合上面那个脚本
# 做无水印下载用的，与去广告无关；脚本没了之后它只会改变抖音的 API 走向、增加出问题的概率，一并剔除。
https://aweme.snssdk.com/aweme/v1/
